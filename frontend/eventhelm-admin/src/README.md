# EventHelm Race Control sprint

Ez a csomag az előző teljes frontendcsomagra épül.

## Tartalom

- új `RaceControlPage`;
- élő radar animáció;
- versenystátusz-kezelő panel;
- zászlópanel;
- motorcsónak-egységek;
- versenyterület-vizualizáció;
- új `/race-control` útvonal;
- új oldalsáv-menüpont.

## Beillesztés

Másold a ZIP `src` mappáját a frontend projektbe, és engedélyezd a fájlok felülírását.

Ezután:

```powershell
cd C:\Users\USER\Desktop\EventhelmV2\frontend\eventhelm-admin
npm run build
npm run dev
```

Ez a sprint egyelőre frontend-demóadatokat használ a Race Control panelen.
A következő lépésben köthető backend-végpontokhoz.
